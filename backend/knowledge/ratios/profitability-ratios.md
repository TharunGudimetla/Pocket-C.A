# Profitability Ratios & DuPont Analysis (ROE & ROA)

## Category
Financial Ratios & Metrics

## Keywords
profitability ratio, ROE, return on equity, ROA, DuPont analysis, net profit margin, asset turnover

## Summary
Calculation of Return on Equity (ROE), Return on Assets (ROA), and DuPont financial decomposition.

## Detailed Content
Profitability ratios measure an entity's ability to generate earnings relative to revenue, balance sheet assets, operating costs, and equity.

### 1. Return on Equity (ROE)
- **Formula**: `ROE = Net Income / Shareholder Equity`

### 2. DuPont 3-Step Analysis
Decomposes ROE into three components:
`ROE = (Net Profit Margin) x (Asset Turnover Ratio) x (Equity Multiplier)`
- **Net Profit Margin**: Operating efficiency (`Net Profit / Revenue`)
- **Asset Turnover**: Asset use efficiency (`Revenue / Average Assets`)
- **Equity Multiplier**: Financial leverage (`Average Assets / Equity`)
